## 自有 ChatGPT 账号怎么充值

1. 打开 [套餐页](https://www.payforchat.com/plans)，确认套餐与当前在售时长。
2. 按页面提示填写完整 Session JSON，核对识别出的 **ChatGPT 充值邮箱**，处理账号校验提示后进入支付页。PayForChat 登录邮箱用于订单通知，不决定充到哪个 ChatGPT 账号。
3. 核对优惠后的应付金额和付款方式，再完成付款。普通用户使用微信或支付宝；银行卡需申请开通，以支付页可选项为准。
4. 在我的订单查看处理进度，再登录目标 ChatGPT 账号确认订阅。到账时效以所选套餐和订单提示为准；付款成功与订阅到账是两个步骤。

Session JSON 是敏感访问凭证，即使不是密码也不能公开分享。只在确认域名和用途后提交到指定输入框，不要放进 GitHub Issue、群聊或截图。获取步骤见 [凭证帮助](https://www.payforchat.com/help/chatgpt-access-token)。

## Plus、Pro 100、Pro 200、Pro 500 怎么选

日常使用可先从 Plus 评估；经常遇到用量不足，再比较 Pro 各档包含用量与预算。旧教程里的 Pro 5X、Pro 20X 在本站分别对应 Pro 100、Pro 200；不要把旧名称当成今天固定的额度倍数。

先看 [本站套餐对比](https://www.payforchat.com/compare)，再核对 [OpenAI 官方用量说明](https://learn.chatgpt.com/docs/pricing) 和账号内用量页面。**本站 Pro 充值条件不等于 OpenAI 官网的升级规则**：已有 Plus 的用户不要直接按补差价升级下单，先查账号状态和所选套餐的办理条件。

PayForChat 暂不单卖 Codex 额度。OpenAI 官方为符合条件的 Plus / Pro 用户提供额外 credits 购买，不能把本站限制理解为官方也不支持；具体见上述官方用量说明。

Grok 请走 [Grok 专页](https://www.payforchat.com/grok)；Claude 当前请走 [咨询页](https://www.payforchat.com/claude)。不同产品的购买入口和提交资料不同。

## 售后和发票

订单异常时，在 [原工单或新工单](https://www.payforchat.com/support) 提供订单号、问题发生时间和已遮挡敏感信息的截图，不要重复付款。充值失败、成功后订阅中断和账号受限的处理规则不同，见 [服务条款](https://www.payforchat.com/terms)。第三方代充存在账号与服务条款风险，本仓库不承诺账号不会受限。

个人已完成订单可在我的订单使用 Invoice 按钮下载 PDF 消费凭证；它不是国内增值税发票。采购报销前先确认单位是否接受这种凭证，详见 [采购指南](docs/12-recharge-guides/chatgpt-business-bulk-purchase-2026.md)。
