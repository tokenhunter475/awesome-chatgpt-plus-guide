# PayForChat 银行卡支付怎么申请，优惠券怎么选

普通用户在支付页使用微信或支付宝。银行卡只对已获开通资格的账号显示，不是所有用户默认可选；申请开通也不等于已经完成付款。

## 看不到银行卡，按这几步申请

1. 先按正常流程确认充值账号，进入尚未付款的订单支付页。
2. 找到“需要银行卡支付？”区域，点击“申请银行卡支付”，在新打开的工单中说明需求。入口会带入申请主题和订单信息。
3. 等客服在工单中确认。不要提交银行卡完整卡号、安全码、密码或短信验证码。
4. 收到开通确认后，返回原订单支付页并刷新，查看是否出现银行卡选项。
5. 核对金额后，在付款组件或银行页面完成必要的支付验证。订单进度在我的订单查看。

如果申请入口没显示，或原订单已经过期，从 [提交工单](https://www.payforchat.com/support) 说明情况即可；是否可开通以客服确认和实际付款选项为准。银行卡通过支付核验后按所选套餐办理，不代表充值立即到账。

微信支付有金额限制：当前站点说明订单金额达到 3000 元时不支持微信。已开通银行卡的用户仍应看当前订单列出的可用方式，不要把“仅支付宝”的普通用户提示套用到所有账号。

## 活动券为什么没有再减一次

符合活动条件的券会自动到账；支付页默认按最优惠方式选择，也可手动换券或选择不用券。每单最多使用一张。先看本单可用券，再看优惠后的应付金额，不要把首页活动价和券面额自行相减后当作报价。

若页面提示活动价让利已不低于券面额，本单会保留券；若提示优惠正在用于另一笔待支付订单，先核对那笔订单是否还需要，不要重复创建订单来抢优惠。切换券后等金额更新完成再付款，最终以支付页报价为准。

## 银行或钱包显示已扣款，网站还没变化

回 [我的订单](https://www.payforchat.com/dashboard) 查同一笔订单。保留付款时间和凭证；仍未更新时在原工单补充订单号与已遮挡敏感信息的付款截图。**不要重复付款，也不要将付款成功当成订阅已经开通。**
