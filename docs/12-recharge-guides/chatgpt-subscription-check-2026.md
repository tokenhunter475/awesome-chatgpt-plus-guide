# ChatGPT 订阅怎么查，提示无法充值怎么办

先查清“哪个账号、什么套餐、是否还在有效期”，再决定是否购买。一次查询失败不能证明账号是 Free，也不能证明它已经被封禁。

## 查询之前，确认你愿意提交这份凭证

[PayForChat 订阅状态查询](https://www.payforchat.com/tools/token-check) 会使用你提交的 Session JSON 查询订阅。页面声明不保存 Token；这是站点的处理说明，Session 本身仍是敏感访问凭证。也可以先直接在 ChatGPT 的订阅设置中查看状态。

决定使用查询工具后：

1. 在 ChatGPT 登录目标账号，确认没有登录成另一位家庭成员或另一个工作账号。
2. 按查询页的“打开 Token 页面”指引，在同一浏览器打开凭证页。
3. 将完整 JSON 粘贴到查询框，点击“查询订阅状态”。不需要向客服发送密码或验证码。
4. 先核对返回的账号，再看套餐、是否在期、周期起止、续费状态和购买渠道；若有字段缺失，不要自行补猜。
5. 查询后清空输入，保存结果时遮挡邮箱、账号标识和凭证。

## 查询结果怎么用于下单判断

| 看到的情况 | 下一步 |
|---|---|
| 账号不对 | 退出错误账号，登录目标账号后重新获取凭证；不要继续付款 |
| 订阅仍在有效期 | 先看当前套餐办理条件；取消自动续费不等于当前订阅已到期 |
| 普通账号，且能正常使用 | 再进入购买页接受实时校验；查询结果不代替下单审核 |
| 显示 App 内购渠道或续费状态有疑问 | 先核对原购买渠道的订阅记录，再确认是否适合本次办理 |
| 查询失败、凭证失效或数据不完整 | 重新登录并获取完整 JSON；仍失败就联系支持，不要反复新建订单 |
| 提示欠费或账号受限 | 核对原订阅账单和账号提示，请支持人员确认；不要只靠套餐名称判断可用性 |

本站暂不支持已有 Plus 账号补差价升 Pro。组织管理的账号还要向管理员确认个人空间和工作区的订阅归属，不能直接把工作区席位当个人套餐续费。

## 已付款后被提示不能充值

先回原订单看具体提示，记录当前订阅情况并提交 [工单](https://www.payforchat.com/support)。不要把所有等待状态理解成充值失败，也不要根据旧文章承诺“等到期一定自动继续”。继续处理、补充信息还是退款，需要结合该笔订单确认。

**订单状态与账号状态要分开看**：查询到在期订阅，不一定说明刚付的那笔订单已经完成；订单标记完成，仍需要核对是否登录了正确账号。如果显示不一致，按下面的会员状态排查文章处理。
