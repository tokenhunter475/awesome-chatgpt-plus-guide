# API 是什么？给非程序员的 10 分钟入门（2026）

> 本文是「历劫卷」第一篇——不写代码的人也能看懂 API，因为 AI 时代的坑（多付费、被多扣钱、买错东西）一半藏在这三个字母后面。

你可能没写过代码，但你一定见过这个场景：某个 AI 工具说「请填入你的 API Key」。填还是不填？填了会发生什么？钱从哪扣？——这些问题看不懂 API 就答不上来。10 分钟，一次讲清。

捡要紧的说：

1. API 是**程序调用程序的接口**——网页版是你用 AI，API 是程序用 AI。
2. API **按量计费**（用多少 token 付多少钱），网页版订阅**按月付费**——两套钱包、互不相通。
3. 见到「填 API Key」先问三个问题：这工具干嘛的、调用花谁的钱、有没有别的登录方式（比如 ChatGPT 账号登录就不用 API）。

## API 是什么：点菜的比喻

餐厅有两种用法：进店点菜（有菜单、有服务员、环境好），或者后厨外包（你自己的餐厅，请它的厨师来做菜，按菜量结账）。

- **网页版/App** = 进店点菜：界面就是菜单，按月付「餐费」（订阅），体验由店家包办
- **API** = 后厨外包：你（或你用的工具）直接调用它的能力，按每道菜（token 用量）结账

API（应用程序编程接口）就是「后厨对外接单的窗口」。你不需要懂后厨怎么炒菜，只需要按它的格式下单——这个「下单格式」就是接口规范。

这个比喻我换过好几种讲法，点菜这个留下来了——因为它最准：网页版是堂食，API 是包后厨，钱分开结，就这么简单。

## API Key：你的后厨账卡

API Key 是一串字符（`sk-` 开头的那种），作用是**记账身份**：谁的调用，记谁账上。

由此推出三条安全铁律：

1. **Key = 钱包**。谁拿到你的 Key，谁就能用你的余额。不截图、不发群、不贴进 AI 对话框（对话内容可能被存）。
2. **Key 泄露的处理**：立刻去平台后台吊销（revoke）重发，动作要快过心痛。
3. **不同工具用不同的 Key**（能创建多个的话），方便定位是谁在消耗。

## 按量计费怎么算

API 按 token 计费（token 是什么见[大模型原理](../00-ai-fundamentals/what-is-llm-2026.md)）。量级参考（2026 年 8 月官方价）：GPT-5.6 Luna 输入 $1/百万 token——一百万 token 大概是七十几万英文单词，或几十万汉字。日常轻度使用，几美元能跑很久；但挂上自动化脚本或 Agent（每轮循环都在烧）就是另一个量级——具体算账方法见 [DeepSeek 涨价解读](../01-models-and-tools/deepseek-api-price-hike-2026.md)的示例。

和订阅的完整对照（哪个场景该用哪个钱包）见下一篇：[API 额度 vs 订阅](api-credits-vs-subscription-2026.md)。

## 什么人在用 API

- **开发者**：把 AI 能力嵌进自己的产品或脚本
- **第三方工具用户**：很多 AI 工具不自带模型，让你填 Key「自带酒水」
- **自动化玩家**：批量处理文档、定时任务、机器人——网页版做不到的事

如果你只是「和人聊」的需求，API 和你无关，订阅/免费网页版是对的工具——别被「API 更高级」的说法带偏，高级不等于适合。

## 常见疑问快答

**「工具让我填 Key，我该填吗？」** 先搞清楚：这工具做什么、花的是你账上的钱（是）、有没有替代登录方式。正规工具都支持随时撤销授权。

**「API 能共用一个账号的订阅吗？」** 不能——这就是下一篇的主题，两套体系互不相通。

**「按量计费会不会失控？」** 会，所以正规平台都有预算上限设置（monthly budget），充值后第一件事就是设上限。细节见[血的教训合集](ai-pitfalls-lessons-2026.md)里的真实案例。
