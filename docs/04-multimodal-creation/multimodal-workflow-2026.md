# 多模态进工作流：截图问答、设计稿转代码、配图一条龙（2026）

> 实战口径 2026 年 8 月；功能入口以各产品实际界面为准。

单聊「图片模型」「视频模型」容易飘——真价值在于把它们**当接口嵌进已有工作流**。这篇是多模态卷的收尾：四个已经跑通的日常场景，每个给完整链路。看完你可以直接把第 4 个场景整个搬走。

如果你只想看结论：

1. 多模态对普通人的日常价值排序：**截图问答 > 配图生产 > 拍照识别 > 设计稿转代码**（越往后越专业，但天花板越高）。
2. 共同心法：**图是输入也是输出**——把「看图」和「出图」接进同一件事，才是工作流。
3. 程序员专属红利：Codex 能直接吃设计稿截图生成代码，还原度七成起。

## 场景一：截图问答（所有人，每天都能用）

遇事不决先截图——这是多模态时代的第一 reflex：

- 软件报错弹窗 → 截图贴进 ChatGPT：「这是什么错，怎么解决」
- 看不懂的英文界面 → 截图：「把这段翻译并解释这个设置是干嘛的」
- 一张复杂图表 → 截图：「图里的关键结论是什么」

关键认知：**截图比文字描述更精确**。你打字形容一个报错容易漏信息，截图不会。AI 读图能力（OCR + 理解）已经稳定，这是多模态里投入产出比最高的一个习惯。

## 场景二：拍照识别（现场信息的入口）

拍到什么问什么：设备铭牌（「这个型号的默认密码怎么重置」）、植物病害、商品标签比价、外语菜单。摄像头成了 AI 的眼睛——注意隐私边界，别拍带他人隐私的东西上传（见[数据安全](../00-ai-fundamentals/ai-data-security-2026.md)）。

## 场景三：设计稿转代码（程序员的天花板场景）

Codex 支持图片输入，直接吃设计稿：

> 根据这张截图实现一个 React 组件，使用 Tailwind CSS，响应式设计，配色和布局尽量还原。

实测参考（社区口径）：Figma 截图 → React 组件还原度约 70-80%；手绘草图 → 可用原型。完整流程：

1. 设计稿截图（或手绘拍照）
2. 连同技术栈约定一起发给 Codex（约定放进 AGENTS.md 更省，见[记忆与配置](../03-codex-tutorials/codex-memory-and-config-2026.md)）
3. 生成初版 → 对照截图提修改（「按钮间距收紧、标题加粗」）
4. 让它补响应式和边界情况

这条链路把「设计 → 前端」的翻译成本压掉一大半。提示词细节见 [Codex 提示词实战](../03-codex-tutorials/codex-prompt-guide-2026.md)。

## 场景四：一篇文章的配图一条龙（完整搬走）

以写一篇公众号文章为例，多模态串起全流程：

1. **写作**：文字模型起草（[提示词](../02-chatgpt-getting-started/prompt-engineering-basics-2026.md)给足上下文）
2. **配图**：[AI 生图](image-models-guide-2026.md)出封面和插图——提示词固定风格只改主体，保证系列感
3. **图内文字**：短词组直接生成；长文案让图留白，编辑器里后期加字
4. **头图动起来**：选一张最好的图，[图生视频](video-models-guide-2026.md)做 5 秒动态版
5. **朗读版**：文案丢 TTS 出配音（见[音频入门](audio-and-voice-ai-guide-2026.md)），文章变播客

一条链走完，一个人就是一支内容小队。这条流水线的每一环都可以单独用——按需取用，不必全套。

## 丑话说在前面：多模态不是全部

- **精确性要求高的图**（工程图、数据图表定稿）：AI 生图不可靠，老老实实用专业工具；数据可视化更该让代码画（Codex 写图表代码又快又准）。
- **长视频**：视频模型仍停留在短素材阶段（见[视频入门](video-models-guide-2026.md)）。
- **别为用而用**：一段文字讲得清的事，配一张 AI 图不加分，反而稀释。

## FAQ

Q: 截图里有机密信息怎么办？

A: 先脱敏（打码关键数据）再上传——把上传的内容当作「可能被看到」处理（见[数据安全](../00-ai-fundamentals/ai-data-security-2026.md)）。

Q: 免费账号能用多模态吗？

A: 图片理解（读图）多数产品免费可用；生图、生视频通常随订阅档位给额度。

Q: 设计稿转代码还原不到 100%，价值在哪？

A: 70-80% 的还原意味着首屏结构、布局、配色一次到位，剩下是微调。对比从零手写，省的是「翻译」时间，不是全部时间。

Q: 这些场景哪个最先学？

A: 截图问答——零成本、当天见效、永久受益。
