# 用 AI 会泄露隐私吗？数据安全与账号保护实用指南（2026）

> 本文是 AI 基础概念第 6 篇；各产品隐私政策会更新，关闭入口以官方设置页实时为准。

「把公司代码贴给 AI 会不会被拿去训练？」「ChatGPT 是不是在偷听？」——数据安全是用 AI 前最值得花十分钟搞清的问题。这里梳理清楚风险的实际边界与防护方法：

1. **主要风险来自输入行为，而非「AI 偷听」**——绝大多数泄露是使用者主动将敏感内容贴进对话导致的，并不是后台窃听。
2. **付费用户的对话默认不用于模型训练**，免费用户通常默认开启、但可手动关闭——在设置里关闭是首要防线。
3. **贴进对话框的内容，一律当作「可能被别人看到」来对待**。

## 你的对话数据去了哪里

主流 AI 产品对对话数据的处理分三层：

| 用途 | 说明 | 典型默认策略（2026 口径） |
|---|---|---|
| 提供服务 | 处理你的请求、维持上下文 | 必然发生，短期留存 |
| 改进模型 | 用对话数据训练下一代模型 | 免费版多数默认开、可关；付费版多数默认关 |
| 人工审核 | 抽样对话由人工检查质量 | 有争议内容时概率高，通常有提示 |

**「不用于训练」不等于「不存储」**。服务端仍需留存对话一段时间（用于 Abuse 审查和合规要求），差别仅在于内容会不会进入模型参数。关掉训练授权能防止数据被模型在后续回答中复述，但数据依旧保存在服务器上。

## 五分钟做完的设置

1. **关闭训练数据授权**：ChatGPT 在 设置 → 数据控制 里关闭「帮助改进模型」；其他产品找同类开关。
2. **关闭聊天记录/历史**（如果不需要跨设备同步对话）：部分产品关闭后对话默认不留存。
3. **开启账号二步验证**：AI 账号绑定了邮箱与付费订阅，防范盗号损失。
4. **检查已连接的第三方授权**：排查已安装的插件与集成，撤销不再使用的访问权限。

## 六个安全使用习惯

1. **脱敏再粘贴**：代码里的密钥、token、数据库地址换成占位符（`sk-xxx`）再发送。
2. **客户和公司真名替换**：合同分析、邮件润色等场景，用「A 公司」「客户 B」代替真实名称。
3. **不贴身份证件**：护照、身份证、银行卡照片不要发给 AI 处理，人工审核环节有抽检查看的可能。
4. **公司代码分级**：核心算法和密钥逻辑严禁粘贴；通用报错、语法、架构类问题可以正常询问。有合规要求的团队应采购企业版（数据隔离承诺写入合同）。
5. **专用独立密码**：AI 账号属于高价值撞库目标，应配置独立密码并开启二步验证。
6. **定期清理历史**：涉及敏感业务的对话用完即删，避免在历史记录中长期留存。

## 关于「AI 偷听麦克风」的说法

目前没有证据表明主流 AI 产品存在后台监听麦克风的行为。「刚聊过就刷到相关广告」通常源于历史搜索记录与算法画像的巧合。实际的数据风险集中在云端对话存储和账号安全，而非设备麦克风。

## 什么情况必须谨慎

- **员工用个人账号处理公司数据**：数据脱离企业控制边界，通常违反企业内部合规规范——应使用企业版或公司明确审批的工具。
- **法律、医疗、金融建议**：AI 输出不构成专业意见，涉及重大决策须由专业人士复核。
- **未成年使用**：各产品均设有年龄门槛（通常 13 岁以上），必要时使用家长控制设置进行限制。

## FAQ

Q: 关掉「用于训练」后，对话就绝对安全了吗？

A: 不是。关闭后数据只是不再进入训练集，服务方仍会按留存政策保存一段时间。对于高度敏感的信息，唯一安全的做法是不贴进对话框。

Q: 付费版和免费版在隐私上有区别吗？

A: 有。付费订阅通常默认不将数据用于训练，留存周期也更短，这也是企业用户采购企业版的核心原因之一。具体以各产品当前的隐私协议为准。

Q: 用 API 调用比网页版更安全吗？

A: 通常条款更严格。主流厂商的 API 普遍明确承诺默认不把请求数据用于模型训练（2026 年主流口径），这也是多数企业选择 API 集成的原因。

Q: Codex 读我的整个仓库，安全吗？

A: Codex 在授权范围内读取文件并在沙盒中执行命令，权限模式由本地控制（见[常用命令](../03-codex-tutorials/codex-cli-tutorial-2026.md)的 `/approvals`）。涉及企业代码需在合规框架下运行，并在忽略规则中排除密钥与配置文件。
