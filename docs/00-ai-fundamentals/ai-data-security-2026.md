# 用 AI 会泄露隐私吗？数据安全与账号保护实用指南（2026）

> 本文是 AI 基础概念第 6 篇；各产品隐私政策会更新，关闭入口以官方设置页实时为准。

「我把公司代码贴给 AI 会不会被拿去训练？」「ChatGPT 是不是在偷听？」——数据安全是用 AI 前最值得花十分钟搞清的问题。这篇讲清风险的真实边界和可控手段。

总而言之，就下面几条：

1. **主要风险不是「AI 偷听」，而是你自己把敏感内容贴进了对话**——绝大多数泄露是输入行为造成的，不是产品后台的锅。
2. **付费用户的对话默认不用于模型训练**，免费用户通常默认授权、但可手动关闭——去设置里关掉是最有效的单点动作。
3. 记住一条铁律：**贴进对话框的内容，当作「可能被别人看到」来对待**。

## 你的对话数据去了哪里

主流 AI 产品对对话数据的处理分三层：

| 用途 | 说明 | 典型默认策略（2026 口径） |
|---|---|---|
| 提供服务 | 处理你的请求、维持上下文 | 必然发生，短期留存 |
| 改进模型 | 用对话数据训练下一代模型 | 免费版多数默认开、可关；付费版多数默认关 |
| 人工审核 | 抽样对话由人工检查质量 | 有争议内容时概率高，通常有提示 |

关键认知：**「不用于训练」不等于「不存储」**。服务需要留存对话一段时间（ Abuse 审查、法律要求），差别在于会不会变成模型参数的一部分。所以关掉训练授权降低了「数据被模型复述出去」的风险，但不改变「数据存在于服务器」的事实——这才是铁律存在的原因。

## 五分钟做完的设置

1. **关闭训练数据授权**：ChatGPT 在 设置 → 数据控制 里关闭「帮助改进模型」；其他产品找同类开关。
2. **关闭聊天记录/历史**（如果不需要跨设备同步对话）：部分产品关闭后对话默认不留存。
3. **开启账号二步验证**：AI 账号绑定的是邮箱 + 付费订阅，被盗损失直接是钱。
4. **检查已连接的第三方授权**：装过的插件、集成会保留访问权限，用不到的撤销。

## 六个安全使用习惯

1. **脱敏再粘贴**：代码里的密钥、token、数据库地址换成占位符（`sk-xxx`）再发。
2. **客户和公司真名替换**：合同分析、邮件润色这类场景，用「A 公司」「客户 B」代替真名。
3. **不贴身份证件**：护照、身份证、银行卡照片不要用于「帮我填表」——人工审核层可能真实看到它们。
4. **公司代码分级**：核心算法、密钥逻辑不进对话框；通用性问题（报错、语法、架构）放心问。有合规要求的团队用企业版（数据隔离承诺写入合同）。
5. **一个密码只用在 AI 账号**：AI 账号是被撞库攻击的高价值目标（带订阅），独立密码 + 二步验证。
6. **定期删历史**：敏感对话用完即删，别让敏感内容在历史记录里躺半年。

## 关于「AI 偷听麦克风」的说法

没有证据表明主流 AI 产品在偷听。这类感觉多来自「刚聊过就看到相关广告」——更可能的解释是算法画像巧合（你之前搜过相关内容）。真正的数据风险面在云端对话内容和账号安全，不在麦克风。

## 什么情况必须谨慎

- **员工用个人账号处理公司数据**：数据出了公司控制范围，多数企业规范禁止——用企业版或公司批准的工具。
- **法律、医疗、金融建议**：AI 输出不构成专业意见，涉重大决策必须找专业人士复核。
- **未成年使用**：各产品有年龄门槛（通常 13 岁以上），家长设置里有限制手段。

## FAQ

Q: 关掉「用于训练」后，对话就绝对安全了吗？

A: 不是。它只是不再进入训练数据；服务仍会按政策留存一段时间。绝对敏感的内容唯一安全的做法是不贴。

Q: 付费版和免费版在隐私上有区别吗？

A: 有。付费订阅通常默认不用于训练且留存策略更短，这是企业用户普遍买企业版的原因之一。具体以各产品隐私政策条款为准。

Q: 用 API 调用比网页版更安全吗？

A: 通常承诺更严格——主流厂商的 API 明确承诺默认不将请求数据用于训练（2026 年主流口径）。这也是很多公司走 API 集成的原因。

Q: Codex 读我的整个仓库，安全吗？

A: Codex 在你的授权范围内读取文件并在沙盒执行命令，权限模式可自己控制（见[常用命令](../03-codex-tutorials/codex-cli-tutorial-2026.md)的 `/approvals`）。企业代码建议在合规框架内使用，密钥类文件加入忽略规则。
