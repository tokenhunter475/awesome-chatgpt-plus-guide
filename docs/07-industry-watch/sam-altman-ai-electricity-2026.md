# Sam Altman：AI 将像水电一样按量计费（2026）

> 事实口径：2026 年 3 月 14 日，华盛顿 BlackRock 美国基础设施峰会，据 Digit 等报道。

「AI 会变成像电力一样的计量服务(metered service)。」——2026 年 3 月，Sam Altman 在 BlackRock 峰会上说出这句话时,台下坐的是基建投资人。这个比喻不是随口打的:电力行业用了上百年才建成的「按表付费」模式,被他画进了 AI 的未来。

先说结论：

1. **计量付费 = 用多少付多少**,替代现在的固定月费——轻度用户可能更省,重度用户账单可能上涨。
2. 这还是个**愿景表态**,不是产品公告;但它和 OpenAI 的动作(API 预付费、Sora 关停、算力集中)方向一致。
3. Altman 自己的管理方式也是信号:他先让 AI 评估产品想法,再和人讨论。

## 他到底说了什么

四层意思:

- **AI 即公用事业**:智能像电和水一样,工作、学习、解决问题时「拧开就用」
- **能力在扩展**:现在 AI 能干几小时的活,未来承担数天到数周的项目
- **他自己就这么用**:管理 OpenAI 时,经常先让 AI 评估新产品想法和商业计划,再进团队讨论
- **基建在铺路**:与微软、Oracle 合建数据中心,与软银等探索全球芯片计划

## 对订阅用户意味着什么

现在的格局是「订阅制为主」:Plus $20/月封顶,重度用户其实是被补贴的。如果真走向计量制:

| 用户类型 | 订阅制(现在) | 计量制(假想) |
|---|---|---|
| 轻度(每天几十条) | 可能亏 | 大概率省 |
| 重度(Codex 长任务、批量生图) | 被补贴,爽 | 账单可能明显上涨 |

这个方向其实已经在发生,只是没换牌子:API 一直是纯计量([双钱包](../06-api-and-relays/api-credits-vs-subscription-2026.md)),DeepSeek 涨价后重度 API 用户的月账单已经摸到订阅的好几倍(见[涨价解读](../01-models-and-tools/deepseek-api-price-hike-2026.md))。Altman 这番话等于把趋势挑明了。

也别过度解读——**计量制落地前,订阅制仍然是对轻度用户更友好的模式**,固定月费就是成本上限。真切换那天,用法克制的习惯会突然变得值钱。

## FAQ

Q: ChatGPT 马上要改按量计费吗?

A: 没有。这是峰会上的愿景表态,没有产品时间表。短期订阅制不动。

Q: 按量计费对普通用户是坏消息吗?

A: 不一定。轻度用户在计量制下通常更省;重度用户的成本会更真实地反映用量。怕的是「计量价格定得离谱」,那是监管和竞争要管的事。

Q: 这和 API 计费有什么区别?

A: API 已经是计量制。他说的是**消费端产品(ChatGPT)**未来也可能走这条路——对话、生图、视频都插表算钱。

Q: 现在该做什么准备?

A: 不用做什么。但可以开始留意自己的真实用量结构(用量页有统计)——无论未来哪种计费,知道自己花在哪都是优势。
