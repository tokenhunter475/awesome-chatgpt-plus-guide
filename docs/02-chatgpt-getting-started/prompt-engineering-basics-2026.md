# 提示词入门：怎么向 AI 提问才能得到好答案（2026）

> 原理适用于所有大模型产品（ChatGPT / DeepSeek / Claude）；「提示词工程」听起来唬人，核心就四个技巧。

同一个 AI，有人用它十分钟出一份像样的方案，有人得到一堆正确的废话。差别不在模型，在提问。这篇讲四个核心技巧，每个配对照示例，看完立刻能用。

挑重点说：

1. 提示词的本质是**给足上下文 + 说清要求**——AI 只能基于你给的信息生成（原理见[大模型是什么](../00-ai-fundamentals/what-is-llm-2026.md)）。
2. 四个技巧：**角色设定、背景上下文、输出格式、分步走**。
3. 最重要的一条：**第一版不满意很正常，用修改指令迭代收敛**，别推倒重来。

## 技巧一：角色设定——告诉它以什么身份回答

在问题前加一句身份设定，回答的专业口径立刻不同：

> ❌ 「这段代码有什么问题？」
> ✅ 「你是一个有 10 年经验的安全工程师，审查这段代码，重点找安全漏洞。」

原理：角色设定改变了模型调用的「知识分布区域」。注意角色要具体（「资深安全工程师」优于「专家」），且别迷信——设定「你是世界首富」并不能让它给出更好的理财建议。

## 技巧二：背景上下文——AI 不知道你的具体情况

默认状态下，AI 对你一无所知：不知道你是谁、给谁写、用在哪。漏掉背景是最常见的失败原因：

> ❌ 「帮我写一封催款邮件」
> ✅ 「帮我写一封催款邮件。背景：对方是合作两年的老客户，欠款 3 个月共 5 万，之前关系良好，这半年对方业务出了问题。目标：催款但保住合作关系。语气：客气但明确。」

背景五要素：**谁（你）、对谁（受众）、什么事、目标、限制**。一次说清，胜过五轮追问。

## 技巧三：输出格式——明确要什么形态的结果

不说格式，AI 就猜一个「均衡但平庸」的形态：

> ✅ 「用表格对比这三个方案，列：价格、优缺点、适合人群」
> ✅ 「分三段写，每段不超过 100 字，第一句必须是结论」
> ✅ 「只输出代码，不要解释」

格式要求越具体，返工越少。进阶玩法：**给它模板**——「按这个格式填：……」直接贴你想要的样板。

## 技巧四：分步走——复杂任务拆开问

一次问一个复杂大问题，AI 容易在多个目标间和稀泥。拆开：

> ❌ 「帮我做一个完整的运营方案」
> ✅ 第一步：「列出这个产品的 5 个核心用户难题」
> → 第二步：「针对难题 1，给 3 个解决方向」
> → 第三步：「把方向 2 展开成可执行的周计划」

每步基于上一步的结果收敛，质量远高于一次性甩锅。这也是和 Agent 协作的原理基础——Agent 的「规划」组件干的就是这个拆解动作（见 [AI Agent 是什么](../00-ai-fundamentals/what-is-ai-agent-2026.md)）。

## 三个高频误区

1. **把「请」「麻烦」当提示词**——客气话不改变输出质量，删掉不影响，背景信息才影响。
2. **一次对话里反复换主题**——上下文互相污染。换主题开新会话（见 [ChatGPT 使用入门](chatgpt-beginners-guide-2026.md)）。
3. **相信「万能咒语」**——网上流传的「神秘提示词」多数是角色设定 + 格式要求的包装，四个技巧自己组合就够了。

技巧就这四个，真没了。网上那些「提示词大师课」讲的也是这些，换个名词收你钱罢了。

## 一个通用模板（抄走即用）

```
角色：你是 [具体身份]
背景：我在 [情况]，这是 [补充信息/材料]
任务：帮我 [做什么]
要求：[格式/长度/语气/限制]
验证：完成后 [怎么算做好了]
```

不是每次都要填满五项——**卡壳的时候按这个清单检查漏了哪项**，比背模板更有用。

## FAQ

Q: 提示词有「标准答案」吗？

A: 没有。同一个问题不同问法都可行，判断标准只有一个：输出是不是你要的。不满意就换一个给法重试。

Q: 中文提示词比英文差吗？

A: 日常任务差距不大；术语密集或需要特定文风时，中英混合（英文提问要求中文回答）偶尔更稳。

Q: 为什么 AI 有时无视我的格式要求？

A: 常见原因：要求埋在长段落里没被识别。把格式要求单独成行、放在提问末尾（模型对结尾指令的遵循度更高），或直接「重复一遍我的格式要求再开始」。

Q: 编程任务的提示词有特殊技巧吗？

A: 有，核心是给上下文（框架、版本、参考代码）和验收标准。专门一篇见 [Codex 提示词实战](../03-codex-tutorials/codex-prompt-guide-2026.md)。
