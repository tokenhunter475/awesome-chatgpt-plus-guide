# 已经付款，ChatGPT 为什么还显示 Free

先确认充给哪个账号，再核对订单进度。显示 Free 可能与登录账号、页面刷新或订阅处理有关，仅凭这个标签不能断定付款失败，也不能断定只是缓存。

## 第一步：核对登录账号

检查当前 ChatGPT 账号是否与订单的充值邮箱一致。PayForChat 登录邮箱用于本站订单和通知，不一定是充值目标。多账号用户尤其要确认浏览器和手机 App 登录的是同一个账号。

## 第二步：看订单是否完成

打开 [我的订单](https://www.payforchat.com/dashboard)，找到对应订单：

- 付款工具显示扣款，但订单仍未确认付款：保留支付时间和付款凭证，联系支持核查，不要再付一次。
- 已付款、订单还在处理：按订单提示等待；超过提示时间或需要补充资料时，在原工单跟进。
- 订单已完成：进入下一步核对实际订阅。

不要把支付成功页面当作订阅开通证明，也不要通过重新下单试图加快已有订单。

## 第三步：刷新并核对订阅记录

刷新网页或重启 App，必要时退出后重新登录，在 ChatGPT 订阅设置中查看套餐。若你选择使用本站工具，也可按 [订阅查询指南](../12-recharge-guides/chatgpt-subscription-check-2026.md) 查询；查询失败不是 Free 的证据。

本站帮助中心建议，订单完成后核对账号并刷新，仍显示 Free 可再等 5–10 分钟；超过 30 分钟仍异常，带订单号提交工单。这是处理建议，不是每笔订单的到账保证。

如果是此前已正常使用、后来突然掉档，同时检查原购买渠道的取消、退款或扣款通知。不要仅凭“欠费”“Free”等单个字段判断异常原因。

## 第四步：把有用的信息交给支持

PayForChat 订单走 [提交工单](https://www.payforchat.com/support)；同一问题尽量在原工单补充：订单号、付款时间、当前订单状态、实际看到的套餐与错误提示、已经尝试的步骤。

截图先遮挡完整邮箱、账号标识、付款账户和凭证。不要附 Session JSON、银行卡完整信息或验证码，更不要把这些内容放到 GitHub Issue。直接向 OpenAI 或 App 商店购买的订阅，应联系对应购买渠道。

是否继续处理或退款，要结合订单核查结果和 [服务条款](https://www.payforchat.com/terms)，不能把成功后的订阅中断与从未充值成功混为一谈。
