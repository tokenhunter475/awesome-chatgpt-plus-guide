# Codex 额度不够用？升级、加购还是换按量：三条路算账（2026）

> 数据口径:2026 年 8 月;消息数为社区实测区间,随负载和任务浮动。

额度又见底了。第三条 refactor 任务跑到一半,`usage limit` 弹窗准时上班。加钱之前先算账——同样的预算,三条路买到的量差很多。

先说结论：

1. **偶尔超额**:Plus + 按需买 Credits,最便宜。
2. **每周都超额**:升 Pro 5X($100/月,额度约 Plus 5 倍)。
3. **天天超额 + 并行任务**:Pro 20X($200/月,约 20 倍;单价算下来 20X 反而更划算)。
4. 先用两个**免费杠杆**:轻任务切小模型,额度能拉长 2.5-3.3 倍。

## 先看自己处在哪一档

社区实测的每 5 小时窗口消息量区间(GPT-5.6,任务大小不同浮动大):

| 套餐 | 每 5 小时约 | 相对量 |
|---|---|---|
| Plus($20/月) | 15-80 条 | 1x |
| Pro 5X($100/月) | 75-400 条 | 5x |
| Pro 20X($200/月) | 300-1600 条 | 20x |

两个官方细节别漏:Pro 两档**模型完全相同**,差的只是量(5X/20X 可随时在设置里互切);$100 档上线时的 10 倍促销已在 2026 年 5 月 31 日结束,现在按标准 5 倍算。

## 三条路的算账逻辑

**路 1:Credits 加购(Plus/Pro 都可)。** 撞限时,订阅额度先扣、扣完自动用 Credits。**判断公式:一年超额几次?** 每月最多一两次冲刺周 → 加购比升级便宜;基本每周都要买 → 升级,因为反复加购的钱很快超过档位差价。

**路 2:升套餐。** 每周撞墙选 5X;5X 还不够(说明你在跑并行任务或超长任务)上 20X——注意**20X 是两倍价格买四倍容量**,重度用户算单价反而更划算。国内用户升级的支付卡点(国内卡被 Stripe 拒)可走代充:在自有账号上完成订阅、微信支付宝付款,以 [PayForChat 套餐页](https://payforchat.com/plans?ref=github)的实时价格和到账时效为准。

**路 3:改 API 按量。** 没有 5 小时窗口和周上限,适合用量极不规律或接自动化的场景。但持续重度使用的 API 账单可能超过 $200/月——按量是「灵活」,不是「便宜」(见[双钱包](../06-api-and-relays/api-credits-vs-subscription-2026.md))。

## 两个免费的杠杆,先拧了再掏钱

- **轻任务切小模型**:日常小修改走轻量档,额度窗口能拉长约 2.5-3.3 倍——`/model` 一秒钟的事
- **避开 Fast 模式烧钱**:某些加速选项按约 2.5 倍速率烧额度,除非赶时间,默认关
- 顺手一提:任务描述写好上下文和验收标准,减少来回试错,是最被低估的省额度手段(见[提示词实战](../03-codex-tutorials/codex-prompt-guide-2026.md))

我自己的顺序永远是:先拧免费杠杆 → 观察 two 周 → 确认是稳定超额而不是偶尔冲刺,再动钱包。多数人高估了自己的用量稳定性。

## FAQ

Q: Codex 额度能单独充值吗?

A: 不能,额度跟套餐走。想要「单独补量」的效果,要么买 Credits,要么走 API 按量。

Q: Plus 升 Pro 有什么限制?

A: 已有 Plus 未到期时通常不能直接转 Pro(等到期或换号),决策前想清楚——见[套餐对比](../02-chatgpt-getting-started/chatgpt-plans-comparison-2026.md)。

Q: 判断自己该不该升级的最快方法?

A: 看撞墙频率:一周多次撞 5 小时窗口 → 5X;连周上限都撞 → 直接 20X;一个月一两次 → Credits。`/status` 里有你的历史用量,别凭感觉。

Q: 额度消耗突然异常快怎么办?

A: 先查 status.openai.com——2026 年 6 月就有过「消耗异常偏快」的官方事故。确认非事故再检查自己的任务规模和模型选择(机制见[用量上限说明](../03-codex-tutorials/codex-usage-limits-2026.md))。
