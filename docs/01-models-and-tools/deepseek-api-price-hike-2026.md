# DeepSeek API 涨价解读：峰谷定价、缓存命中涨 1100%，开发者怎么算账（2026）

> 事实口径：8 月 13 日官宣，2026 年 8 月 17 日 0 点（北京时间）生效。

DeepSeek 全线改为峰谷分时计价，多项价格上涨两倍到十倍。受影响最大的是白天高频调用且依赖长上下文的场景，尤其是编程 Agent。

核心变化：

1. **调用量小、能错峰的场景**：影响较小，空闲时段价格是高峰的一半，挪动执行时间即可。
2. **白天高频写代码、跑 Agent 的场景**：成本最高涨到原来的 3 倍多（下文有测算）。
3. **依赖缓存命中的长上下文场景**（编程助手、RAG）：成本增幅最高，涨幅最大的计费项正是缓存命中输入。

## 价格变动：两张表

**DeepSeek-V4-Pro（元/百万 tokens）：**

| 计费项 | 涨价前 | 空闲时段 | 高峰时段 | 高峰涨幅 |
|---|---|---|---|---|
| 输入（缓存命中） | 0.025 | 0.15 | 0.30 | +1100% |
| 输入（缓存未命中） | 3 | 4.5 | 9 | +200% |
| 输出 | 6 | 13.5 | 27 | +350% |

**DeepSeek-V4-Flash（元/百万 tokens）：**

| 计费项 | 涨价前 | 空闲时段 | 高峰时段 | 高峰涨幅 |
|---|---|---|---|---|
| 输入（缓存命中） | 0.02 | 0.05 | 0.10 | +400% |
| 输入（缓存未命中） | 1 | 1.5 | 3 | +200% |
| 输出 | 2 | 4.5 | 9 | +350% |

高峰时段：每天 9:00–12:00、14:00–18:00（北京时间），覆盖日常工作时间；空闲价格为高峰一半。

2026 年 5 月，DeepSeek 刚把 2.5 折优惠价转为「永久定价」，不到三个月调价。

## 为什么编程场景受影响最大

涨幅最高的计费项是**缓存命中输入**（+1100%）。编程助手与 Agent 的调用结构通常是多轮交互：每轮请求都要附带对话历史与代码上下文，输入 token 往往是输出的几十倍，且大部分命中缓存。

同时，写代码主要集中在白天，9:00–18:00 基本落在高峰时段，无法像离线批处理任务那样移到半夜。两项叠加，这类调用基本只能按最高价结算。

## 成本测算（假设已标注，量级供参考）

以重度 Agent 用户的典型量级测算：每天输入 5000 万 tokens（80% 缓存命中）+ 输出 200 万 tokens。按 V4-Pro 计：

- 涨价前：约 43 元/天，每月 22 个工作日约 **950 元**
- 涨价后（工作时段高峰价）：约 156 元/天，每月约 **3,400 元**
- 涨价后（全部挪到空闲时段）：约 78 元/天，每月约 **1,700 元**

实际花费取决于调用工具和上下文规模，但结论明确：**高峰期重度使用成本约为原来的 3.5 倍，错峰可降低一半增幅**。

对比固定月费方案：ChatGPT Plus 官方 $20/月（含 Codex 使用）。重度调用下，按量付费的支出已经明显超过订阅费用。订阅的额度规则（5 小时窗口 + 周上限）见 [Codex 用量上限说明](../03-codex-tutorials/codex-usage-limits-2026.md)。

## 应对方案选择

**继续使用 DeepSeek**：调用量小、能够错峰或运行夜间批处理的任务，空闲时段单价仍处于低位，维持原方案即可。

**错峰与调度优化**：将批量任务移至空闲时段，调整缓存策略以减少重复上下文，适合执行时间灵活的场景。

**切换到订阅模式**：白天高频写代码的用户，固定月费订阅（含编程 Agent）支出可控，不受分时计价影响。Codex 的能力与 GPT-5.6 档位见[编程工具对比](ai-coding-tools-comparison-2026.md)。

如果是 7×24 小时运行的自动化流水线，固定订阅无法替代按量计费——订阅模式设有周上限，超量需等待额度重置。这类场景仍需依赖按量计费并尽量错峰。

## FAQ

Q: 涨价影响网页版/App 的免费使用吗？

A: 不影响。这次调整的是 API 按量计费价格，网页版和 App 仍免费。

Q: 高峰时段具体是几点？

A: 每天 9:00–12:00 和 14:00–18:00（北京时间），其余为空闲时段，价格为高峰一半。

Q: 为什么缓存命中涨得最多？

A: 该计费项原本单价较低（0.025 元/百万 token），是长上下文场景的主要成本支撑。编程 Agent 和 RAG 高度依赖缓存命中，调价会直接改变这类场景的账单构成。

Q: 自部署开源版受影响吗？

A: 不受 API 定价影响。自建部署承担的是硬件与运维成本，这也是开源模型的避险价值（见[开源 vs 闭源](open-source-vs-closed-source-models-2026.md)）。
