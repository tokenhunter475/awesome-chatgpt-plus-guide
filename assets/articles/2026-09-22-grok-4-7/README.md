# Official Grok 4.7 charts

Source: [SpaceXAI — Introducing Grok 4.7](https://x.ai/news/grok-4-7), published September 21, 2026. Retrieved September 22, 2026.

These files export the official page's rendered SVG charts. The original chart geometry, ordering, numeric values, axes and model labels are retained. Computed presentation styles were made self-contained, and PNG versions were rasterized for embedding. They are not recreated benchmark plots or PayForChat measurements.

| File | Official view | Comparison scope |
|---|---|---|
| `01-cursorbench-cost` | CursorBench 4.0, Cost tab | Includes GPT-5.6 Sol, not GPT-6 Astra |
| `02-gdpval` | Professional knowledge work / GDPval | Includes GPT-6 Astra |
| `03-aa-briefcase` | Multi-hour office work / AA Briefcase | Includes GPT-6 Astra |
| `04-eebench` | Electrical engineering / EEBench | Includes GPT-6 Astra |
